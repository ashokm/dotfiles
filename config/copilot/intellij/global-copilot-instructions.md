# Global Copilot Instructions

* Use British English.
* Be concise, direct and practical.
* Keep changes focused on the requested task.
* Prefer simple, explicit solutions over clever abstractions.
* Keep functions small and single-purpose.
* Avoid dead code and commented-out code.
* Do not add dependencies unless necessary.
* Never hardcode secrets, credentials or tokens.
* Shell scripts must use `set -o errexit -o nounset -o pipefail` and be shellcheck-clean.
